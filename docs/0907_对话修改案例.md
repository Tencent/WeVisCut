# WevisionCut 对话修改案例

成片出来之后，在 **0907 创作台**左侧对话框里直接说话即可改片子。系统会先理解你的意图，定位到镜头，生成修改计划，再渲染并校验。校验通过后才能预览到最终效果。

一句话原则：**说清楚「改哪个」+「改成什么」**。

---

## 0. 最准的指法：@ 和拖时间轴

不想描述「第几个」时，有两种精确指定方式，指到哪就改哪：

**输入 `@`** —— 对话框会弹出镜头列表，键入数字可过滤，回车或点击即选中，插入成 `@镜头03`。

```
@镜头03 换成海边落日
@子镜头2.1 换成实验室近景
@镜头02 口播改成：现在这碗面要二十块了
```

**拖时间轴片段** —— 把时间轴上任意小段直接拖进对话框，会自动变成对应的 `@镜头NN` 或 `@子镜头N.M`，再补一句要改成什么即可。

`@` 出现时以它为准，同一句里的其他序号说法会被忽略，所以下面这句改的是镜头 04：

```
@镜头04 我刚说的第1个镜头先别管，这个换成大海
```

## 1. 怎么指到某个镜头

下面这些说法都可以定位，不必记内部 ID。

| 指法 | 你可以这样说 | 说明 |
|---|---|---|
| 全片序号 | 第 3 个镜头、第三个镜头、镜头 03 | 按时间轴从 1 数 |
| 中文数字 | 第一个、第十二个 | 一到百都认 |
| 章节 + 序号 | 《跑步机上的原地踏步》第一个镜头 | 先锁章节，再数该章里的第几个 |
| 章节口语 | 跑步机上的原地踏步这一章节第一个镜头 | 「这一章 / 这一段 / 这个部分」都行 |
| 章节开头 | 《物价上涨》这章开头 | 落到该章最早的镜头 |
| 台词原文 | 把「十年前那碗面只要十块钱」那镜换掉 | 用字幕或口播里的原句 |
| 引号短语 | 强调“真正的效率”这句 | 动画、重点常用 |
| 时间点 | 0:12 那里、第 12 秒左右 | 落在该时间所在镜头 |
| 子镜头 | 素材子镜头 2.1 | `大镜序号.子镜序号` |
| 承接上文 | 刚才那个、还是那里、那个也换成… | 接着上一轮改过的目标 |
| @ 提及 | @镜头03、@子镜头2.1、@《章节名》 | 最精确，优先级最高 |

说「素材 / 画面 / 视频 / 片段」时通常就是指镜头，`第 3 个素材` 等于 `第 3 个镜头`。

## 2. 开场和问功能

这些话**不会改片子**，只是对话。

| 你说 | 系统会 |
|---|---|
| 你好 | 打招呼，并提示可以怎么改 |
| 在吗 / 嗨 | 同上 |
| 可以改什么 / 能做什么 / 怎么用 | 列出换素材、调时长、改口播字幕、动画强调、整体优化 |
| 有什么功能 / 支持什么 / 帮助 | 同上 |
| 什么意思 / 没懂 / 解释一下 | 说明怎么把话说清楚 |
| 谢谢 / 辛苦了 / 可以了 | 收尾，不继续改 |
| 取消 / 算了 / 不用改了 / 先别改 | 停止本轮计划 |

也可以把招呼和修改写在一句里，系统会当修改处理：

- 你好，把第三个镜头换成海边落日

## 3. 换画面素材（最常用）

改的是**整个镜头**检索到的画面，不是只改口播。

### 3.1 按序号换

| 你说 | 会做什么 |
|---|---|
| 第 3 个镜头换成摇滚乐队 | 镜头 03 重新检索「摇滚乐队」 |
| 我希望你把第3个镜头视频素材换成摇滚乐队 | 同上，口语更长也行 |
| 第三个镜头换一个大海的视频 | 检索「大海」 |
| 镜头 01 换成城市夜景 | 镜头 01 → 城市夜景 |
| 把第 2 个镜头的画面改成图书馆 | 镜头 02 → 图书馆 |
| 第5个分镜换成 Crowded subway | 中英检索词都可以 |
| 第一个镜头换成海边落日 | 镜头 01 → 海边落日 |
| 第十二个镜头换成实验室近景 | 中文数字 |

### 3.2 按章节换

| 你说 | 会做什么 |
|---|---|
| 跑步机上的原地踏步这一章节第一个镜头换一个大海的视频 | 该章第 1 个镜头 → 大海 |
| 《物价上涨与购买力流逝》第二个镜头换成超市货架 | 该章第 2 个镜头 → 超市货架 |
| 银行里的无声缩水这一章开头换成金库保险箱 | 该章最早一镜 |
| 第 2 章第一个镜头换成股市大盘 | 「第 N 章」 |
| 这个部分第一个镜头换成人群过马路 | 若上文已锁定章节，会接着用 |

### 3.3 按台词 / 语义换

| 你说 | 会做什么 |
|---|---|
| 把「十年前那碗面只要十块钱」那镜换成老街面摊 | 按口播原文定位 |
| 收银台里的钞票变厚了 这一镜换成点钞机特写 | 按字幕定位 |
| 后面跑步机那章开头换成大海 | 模型理解章节 + 开头 |
| 把后面那段开头画面换成大海 | 较口语，模型会尽量落到唯一镜头 |

### 3.4 换完接着换

| 轮次 | 你说 | 会做什么 |
|---|---|---|
| 1 | 第 3 个镜头换成摇滚乐队 | 改镜头 03 |
| 2 | 那个也换成海边落日 | 还是镜头 03，再换成海边落日 |
| 3 | 刚才那个再换一个城市夜景 | 继续镜头 03 |
| 4 | 还是那里，换成人群过马路 | 继续镜头 03 |

## 4. 只换子镜头（更细）

一个大镜头里可能有多段检索视频。要动其中一段，用「子镜头」。

| 你说 | 会做什么 |
|---|---|
| 把素材子镜头 2.1 换成实验室近景 | 只换 2.1 这一段 |
| 子镜头 3.2 换成摇滚乐队 | 只换 3.2 |
| 把素材子镜头7.2换成实验室里操作设备的近景 | 长描述也可以当检索词 |
| 子镜头 1.1 换掉，换成海边日落 | 同上 |

不知道子镜头编号时，先改整个镜头更稳：

- 第 2 个镜头换成实验室近景

## 5. 改时长和节奏

### 5.1 整镜时长

时长变化超过约 20% 时，会先让你**确认**再执行。

| 你说 | 会做什么 |
|---|---|
| 第 2 个镜头调到 5 秒 | 镜头 02 时长 = 5s |
| 第1个镜头改到20秒 | 大幅变长，需要点「确认执行」 |
| 把第三个镜头时长改成 3.5 秒 | 支持小数 |
| 《跑步机上的原地踏步》第一个镜头调到 4 秒 | 章节内第 1 镜 |
| 0:12 那个镜头改到 6 秒 | 按时间点定位后再改时长 |

### 5.2 子镜头时长

| 你说 | 会做什么 |
|---|---|
| 把素材子镜头 7.2 调到 1.5 秒 | 只动这一段的占用时长 |
| 子镜头 2.1 改到 2 秒 | 同上 |
| 子镜头 3.1 时长调到 0.8 秒 | 短切 |

### 5.3 整体优化

| 你说 | 会做什么 |
|---|---|
| 整体优化一下 | 按质量策略重排节奏、去重、补镜 |
| 全片优化 | 同上 |
| 整体优化一下节奏 | 同上 |

## 6. 改口播、旁白、文案

改的是**解说词**，画面不一定一起换。若希望画面跟着文案走，另说一句换素材。

| 你说 | 会做什么 |
|---|---|
| 把第 1 个镜头的口播改成：十年前一碗面只要五块钱 | 重写镜头 01 口播并重配音 |
| 第3个镜头旁白换成：货币变多，钱就不值钱了 | 改旁白 |
| 把「收银台里的钞票变厚了」这句解说改成：钱变厚了，货却没变多 | 先按原句定位，再替换文案 |
| 《物价上涨》第一个镜头文案改成：工资没涨，面价先涨 | 章节 + 文案 |
| 第 2 个镜头口播改成更口语一点：现在这碗面要二十块了 | 口语化改写 |

## 7. 改字幕

只动屏幕字幕，不动口播音频。

| 你说 | 会做什么 |
|---|---|
| 第 1 个镜头字幕改成：十年前，一碗面十块钱 | 只改字幕 |
| 把第3个镜头字幕换成：钱变多了，东西却没变多 | 同上 |
| 「真正的效率」那句字幕改成：真正的效率，是少做无用功 | 按原句定位 |
| 第 2 个镜头字幕改成短一点：面价翻倍了 | 缩短字幕 |

口播和字幕要一起改，分两句或写清楚两件事情：

- 第 1 个镜头口播改成「十年前一碗面五块钱」，字幕也改成这句

## 8. 配乐 / BGM

配乐是全片级，一般不用指定镜头。

| 你说 | 会做什么 |
|---|---|
| 配乐换成轻快电子乐 | 按「轻快电子乐」检索并替换 BGM |
| 背景音乐换成安静钢琴 | 钢琴氛围 |
| 换一首更紧张的 bgm | 紧张风格 |
| 来一首轻松的吉他 | 「来一首」也算换配乐 |
| 把音乐改成科技感电子 | 科技感 |
| 加一段低沉的氛围配乐 | 新增/替换为氛围垫乐 |
| BGM 换成摇滚 | 直接说 BGM 也可以 |

## 9. 动画：强调 / 去掉

短语请用中文引号 `“ ”` 或 `「 」`，系统靠引号锁定原句。

### 9.1 强调

| 你说 | 会做什么 |
|---|---|
| 强调“真正的效率”这句 | 给该句加重点动画 |
| 重点突出「购买力」 | 强调「购买力」 |
| 把“怎样让 AI 成为自己的工具”做成重点 | 关键句强调 |
| 在《未来图景》这章，强调“怎样让AI成为自己的工具” | 先锁章节再强调 |

### 9.2 去掉动画

| 你说 | 会做什么 |
|---|---|
| 把动画“真正的效率”删掉 | 去掉该句动画 |
| 去掉「购买力」上的动画 | 同上 |
| 删除“工具箱革命”这个动画 | 同上 |

### 9.3 一句话里两件事

| 你说 | 会做什么 |
|---|---|
| 在《未来图景》这章，把动画“真正的效率”删掉，并强调“怎样让AI成为自己的工具” | 同一事务里完成删 + 加 |

## 10. 删镜头、重排（会二次确认）

这类会改结构，界面会先出「确认执行」，点了才真正改。

| 你说 | 会做什么 |
|---|---|
| 删掉第 4 个镜头 | 删除镜头 04 |
| 把第三个镜头去掉 | 删除镜头 03 |
| 删除《银行里的无声缩水》第一个镜头 | 章节内删除 |
| 不要第 2 个镜头了，删掉 | 口语删除 |

重排目前更稳的说法是按镜头顺序描述目标顺序；若系统吃不准，会追问。也可以在确认卡片上再确认一次。

误操作了可以说：

- 取消
- 算了
- 然后在事务条上点「回滚」

## 11. 多轮对话完整案例

### 案例 A：先问再改

```
你：你好
助：你好，我是这支片子的剪辑助手。告诉我要改哪个镜头、改成什么就行……

你：可以改什么
助：换素材、调时长、改文案字幕、动画强调、整体优化……

你：第 3 个镜头换成摇滚乐队
助：好的，我来处理：
    · 镜头 03：换成「摇滚乐队」的画面素材
    改动会先渲染再校验，完成后你可以直接预览。
```

### 案例 B：章节定位

```
你：跑步机上的原地踏步这一章节第一个镜头换一个大海的视频
助：好的，我来处理：
    · 镜头 03：换成「大海」的画面素材
```

### 案例 C：改完不满意，接着换

```
你：第 2 个镜头换成超市货架
助：……镜头 02：换成「超市货架」……

你：那个不好看，换成菜市场
助：……镜头 02：换成「菜市场」……

你：还是刚才那个，换成夜市灯火
助：继续改镜头 02
```

### 案例 D：先改画面，再改文案

```
你：第一个镜头换成老街面摊
你：把第 1 个镜头的口播改成：十年前一碗面只要五块钱
你：第 1 个镜头字幕也改成：十年前，一碗面五块钱
```

### 案例 E：看不懂上一条回复

```
助：这几个镜头都对得上，你要改哪一个？
    · 镜头 02 · 物价上涨与购买力流逝 · 现在同样的面要二十块……
    · 镜头 03 · 跑步机上的原地踏步 · 货币总量增加……

你：什么意思
助：需要先定位到唯一镜头。你可以说「第 3 个镜头换成海边落日」……

你：那就第 3 个，换成海边落日
助：好的，我来处理：· 镜头 03：换成「海边落日」的画面素材
```

### 案例 F：时间点 + 时长 + 配乐

```
你：0:12 那里换成 Crowded subway
你：那个镜头调到 6 秒
你：配乐换成轻快电子乐
```

### 案例 G：动画替换

```
你：在《未来图景》这章，把动画“真正的效率”删掉，并强调“怎样让AI成为自己的工具”
```

### 案例 H：中途不想改了

```
你：第 1 个镜头改到 20 秒
助：时长变化较大，需要确认。

你：算了
助：好的，这次不继续改。要撤销已经生效的修改，可以点「回滚」。
```

### 案例 I：一次说两个镜头

```
你：第 1 个镜头换成大海，第 3 个镜头换成摇滚乐队
```

能拆成唯一目标时会一起做；说不清楚时会先追问其中一个。

### 案例 J：全片收尾

```
你：整体优化一下节奏
你：配乐换成安静钢琴
你：可以了，谢谢
```

## 13. 系统可能追问时，你怎么接

目标不唯一时，助手会列出最接近的几个镜头，**不会**只回「没找到唯一目标」。

| 助手在问 | 你可以回 |
|---|---|
| 这几个镜头都对得上，你要改哪一个？ | 第 3 个 / 跑步机那章第一个 / 「货币总量增加」那句 |
| 我还不能确定你指的是哪个镜头 | 补章节名或序号 |
| 需要确认（删除 / 大幅改时长） | 点「确认执行」，或说「取消」 |

接着上一轮时，直接说：

- 第 3 个
- 改那个
- 就是《跑步机上的原地踏步》第一个
- 换成大海（若上一轮已经锁定镜头）

## 14. 改完之后会发生什么

1. 助手先回复计划，例如：  
   `好的，我来处理：· 镜头 03：换成「摇滚乐队」的画面素材`
2. 低风险修改会立刻保存，并开始重渲染、校验。
3. 删除、重排、时长变化很大时，先点「确认执行」。
4. 只有校验通过，才算真正改好，这时再预览。
5. 预览不满意：继续说话换一版，或在事务上「回滚」。

## 15. 说话时的小技巧

**更容易一次改准**

- 同时带上「第几个」和「改成什么」：`第 3 个镜头换成海边落日`
- 章节名尽量用片子里的原标题
- 强调 / 去动画时给短语加引号
- 子镜头用 `2.1` 这种编号
- 多轮时用「刚才那个」减少重复描述

**容易说糊的**

- 只说「好看一点」「高级一点」——太虚，请补画面词
- 只说「后面那段」——请补章节名或序号
- 口播、字幕、画面一次搅在一个「改一下」里——拆开说更稳
- 还没生成成片就对话修改——先等创作跑完

```
[第 N 个镜头 / 《章节》第 N 个镜头 / “原句”那镜] + [换成 / 改成 / 调到] + [画面词 / 文案 / 秒数]
```

例如：

- 第 3 个镜头换成摇滚乐队
- 《跑步机上的原地踏步》第一个镜头换一个大海的视频
- 把第 1 个镜头的口播改成：十年前一碗面只要五块钱
- 第 2 个镜头调到 5 秒
- 配乐换成轻快电子乐
- 强调“真正的效率”这句
